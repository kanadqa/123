# Учет расходов и доходов

Простой офлайн-трекер для учета расходов и доходов. Данные сохраняются в вашем браузере, а для работы в Excel можно экспортировать CSV. Интерфейс разделен на меню (Обзор, Операции, Категории, Настройки), есть диаграммы по категориям и варианты отображения.

## Как пользоваться

1. Откройте `index.html` в браузере.
2. В разделе «Операции» заполните форму и нажмите «Сохранить».
3. В разделе «Категории» добавляйте свои категории и подкатегории.
4. В разделе «Обзор» смотрите сводку и диаграммы.
5. В разделе «Настройки» выберите вариант интерфейса (компактный, комфорт, фокус).
6. Нажмите «Экспорт CSV», чтобы получить файл, который легко открыть в Excel/Google Sheets.
7. Кнопка «Очистить все» удаляет все записи из локального хранилища.

## Категории и подкатегории

Категории и подкатегории задаются вручную в разделе «Категории». Можно создавать подкатегории для любой категории (например, «Еда» → «Еда вне дома»).

## XLSX-альтернатива

Если вам удобнее работать именно в Excel, используйте файл `template.csv` и откройте его в Excel как CSV. Затем сохраните как `.xlsx` при необходимости.

## Запуск локального сервера (необязательно)

Если браузер блокирует доступ к локальному хранилищу при открытии файла напрямую, запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
