# Финансовый контроль

Переосмысленный офлайн‑трекер для учета расходов и доходов. Данные сохраняются в браузере, есть аналитика, категории/подкатегории и несколько вариантов интерфейса (темы и плотность).

## Что нового

- Меню с разделами: Обзор, Операции, Категории, Диаграммы, Настройки.
- Категории разделены на доходы и расходы, можно создавать подкатегории.
- Диаграммы по категориям и подкатегориям.
- В настройках можно выбрать вариант оформления и плотность интерфейса.

## Как пользоваться

1. Откройте `index.html` в браузере.
2. Перейдите в раздел «Операции» и добавьте записи.
3. В разделе «Категории» создавайте свои категории и подкатегории.
4. В «Диаграммах» отслеживайте структуру расходов и доходов.
5. В «Настройках» выберите понравившийся вариант оформления.

## XLSX-альтернатива

Если вам удобнее работать именно в Excel, используйте файл `template.csv` и откройте его в Excel как CSV. Затем сохраните как `.xlsx` при необходимости.

## Запуск локального сервера (необязательно)

Если браузер блокирует доступ к локальному хранилищу при открытии файла напрямую, запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
