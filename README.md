# Учет расходов и доходов

Простой офлайн-трекер для учета расходов и доходов. Данные сохраняются в вашем браузере, а для работы в Excel можно экспортировать CSV.

## Как пользоваться

1. Откройте `index.html` в браузере.
2. Заполните форму «Добавить операцию» и нажмите «Сохранить».
3. Сводка автоматически покажет доходы, расходы и баланс.
4. Нажмите «Экспорт CSV», чтобы получить файл, который легко открыть в Excel/Google Sheets.
5. Кнопка «Очистить все» удаляет все записи из локального хранилища.

## XLSX-альтернатива

Если вам удобнее работать именно в Excel, используйте файл `template.csv` и откройте его в Excel как CSV. Затем сохраните как `.xlsx` при необходимости.

## Запуск локального сервера (необязательно)

Если браузер блокирует доступ к локальному хранилищу при открытии файла напрямую, запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
